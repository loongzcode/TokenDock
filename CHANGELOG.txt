1.1.0
- 单击任务栏平台或设备直接打开对应详情，支持返回全部，单项窗口按内容缩短。
- 状态区分未接入、读取失败、数据过期、等待额度更新；托盘状态入口展示任务栏空间与读取问题。
- 新增 GitHub 正式版本检查和可关闭的启动 / 六小时自动检查；不发送平台凭据。
- API 限流时从同仓库公开发布页检查。下载由用户触发，严格匹配附件、版本、大小及 SHA256。
- 下载支持取消，校验失败、中断或超限时清理临时文件，不自动安装或替换运行中的程序。
- 新增 39 项回归检查，合计 241 项通过；包含点击路由、异常状态、降级查询、损坏包与中途取消。

1.0.1
- 修复已保存的右侧自定义位置在空间不足时跨过应用按钮跳到左侧的问题。
- 任务栏占用检测未完成、失败或结果不完整时等待重新检测，不再用左侧猜测位置代替。
- 原区域恢复空间后自动恢复显示；主动拖动仍可选择其他区域。
- 新增 8 项任务栏位置回归检查，合计 202 项通过。

1.0.0
- 首个 GitHub 正式发布版本，整理源码、构建脚本、使用文档与演示截图。
- 提供 Codex、Claude Code 额度与 Token 指标、DeepSeek API 余额，以及 Windows / BLE 设备电量。
- 支持任务栏嵌入、拖动定位、位置锁定、项目排序、悬停速览、阈值提醒与本机历史趋势。
- 包含经过实机验证的有限 FLX1 2.4G 接收器适配；充电与关机状态单独校验。
- 发布包不包含个人配置、API Key、设备绑定、历史、日志与旧版构建产物。
- Windows 11 x64 已验证，Windows 10 x64 尚待实机验证；当前二进制未签名。

0.7.0
- 新增经过实机确认的 FLX1 2.4G 接收器电量适配，绑定当前接收器指纹与蓝牙身份。
- 仅查询已验证的厂商控制集合，使用型号、在线状态和电量查询，不修改鼠标配置。
- 修复关机后接收器继续返回旧百分比的显示风险：读取前后校验在线状态。
- 充电时显示状态并跳过百分比历史与低电量通知，避免误报满电。
- 蓝牙与接收器数据独立获取、按绑定身份合并，未知接收器不会自动匹配为 FLX1。

0.5.0
- 新增任务栏项目排序，支持排序窗口内拖动、上移下移和跨启动保留。
- 新增额度周期更新与低位恢复提醒，首读、失败与过期数据不触发。
